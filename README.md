## 📂 More Projects

### 🔶 Data Engineering
- [**CarePlus Support Ticket ETL Pipeline**](https://github.com/vamshi-thatipamula/CarePlus_System_Support_Ticket_ETL) – Incremental AWS ETL pipeline on S3, Lambda and Athena with Bronze, Silver and Gold layers, turning 607 tickets and 2,245 logs into two Streamlit dashboards.

### 💬 Generative AI
- [**Customer Feedback Analyzer (Gen AI)**](https://github.com/vamshi-thatipamula/Gen_AI_Customer_Feedback_Analyzer) – Google Gemini, FastAPI, SQLite and Streamlit app that turns restaurant reviews into sentiment, themes and suggested actions.

### 📊 Data Analytics & Visualisation
- [**Sales Insights Data Analysis (Tableau)**](https://github.com/vamshi-thatipamula/Tableau_sales_insights_data_analysis_project) – Three Tableau dashboards on 150,000+ transactions, showing Delhi NCR generated over 50% of revenue.
- [**Exploratory Data Analysis in the Hospitality Domain**](https://github.com/vamshi-thatipamula/Python_Hospitality_Domain_Revenue_Analytics_EDA) – Occupancy and revenue-realisation KPIs on 134,000+ bookings, identifying cancellations and unrealised bookings as major drivers of revenue leakage.
- [**Data Analysis Using SQL**](https://github.com/vamshi-thatipamula/Data_Analysis_using_SQL) – Queried a five-table movie database with joins, CTEs and window functions; higher budgets did not consistently lead to higher IMDb ratings.

### 🐍 Python Applications
- [**Expense Management System**](https://github.com/vamshi-thatipamula/Python_Expense_Tracking_System) – Full-stack expense tracker on FastAPI, Streamlit and MySQL with an interactive Plotly dashboard and Pytest tests.
